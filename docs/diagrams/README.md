# Диаграммы системы

В каталоге находятся диаграммы системы `ИнфоМед`, подготовленные в формате PlantUML.

## Состав

- `use-case-diagram.puml` — диаграмма вариантов использования
- `activity-appointment-booking.puml` — диаграмма деятельности для сценария записи на приём
- `component-diagram.puml` — диаграмма компонентов
- `database-diagram.puml` — диаграмма базы данных

## Как использовать

Диаграммы можно:

- открыть в IDE с плагином PlantUML;
- экспортировать в PNG/SVG через локальный PlantUML;
- вставить в пояснительную записку или техническую документацию.
